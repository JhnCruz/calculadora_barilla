Varilla

Privacidad

Varilla calcula en tu dispositivo. La aplicación no solicita una cuenta ni incluye publicidad o herramientas de análisis.

Los cálculos que guardas se almacenan en el navegador de este dispositivo. El widget de Windows puede mostrar un resumen del último cálculo guardado. Puedes borrar los registros desde Historial y quitar el widget desde Windows.

Cuando eliges compartir un cálculo, Varilla lo entrega al sistema para que selecciones la aplicación de destino. Esa aplicación aplica sus propias condiciones. El texto o archivo que compartes hacia Varilla se procesa en el dispositivo; las medidas válidas se muestran para revisión y solo se guardan si eliges Guardar cálculo.

El proveedor de alojamiento puede registrar información técnica de las solicitudes al sitio según sus propias prácticas.
